【タイトル】簡単時短レシピアプリ

【キャッチコピー】忙しい毎日に、すぐ作れる一品を！

【アプリ概要】

・10〜20分で作れる簡単レシピを一覧表示

・レシピの詳細ページで材料・作り方を確認

・シンプルで迷わず使える構成

【開発した背景】

前職では、仕事終わりに「今日のご飯どうする？」という会話がよくありました。
限られた時間の中でご飯を作らなければならないママが、
少しでも時間を有効活用できるように、
“短時間で作れるレシピだけをまとめたアプリ” を作りたいと思い開発しました。

【画面や機能について】

● レシピ一覧画面

・登録されているレシピを一覧表示

・料理名と調理時間を確認できる

● レシピ詳細画面

・材料

・作り方

・調理時間

以上の3点を確認できるシンプルな構成しました

【使用技術】

■Backend

・Java 17

・Spring Boot 3.x

・Spring MVC

・Spring Security（現在は認証機能オフ）

■Database

・H2 Database

■Frontend

・Thymeleaf

・HTML / CSS

■Build / Tool

・Maven

・IntelliJ IDEA

・GitHub / GitHub Desktop

【ローカル環境での起動方法】

・このリポジトリを clone

・IntelliJ で開く

・kantan_jitan_v1 を Maven でビルド

・KantanJitanV1Application を実行

・ブラウザで http://localhost:8080/recipes/top を開く
